PROBLEM:
--------
❌ "Invalid credentials" error even with correct password
❌ Happens specifically after switching to BCrypt hash passwords

ROOT CAUSE:
-----------
The C# code was trying to verify BCrypt hashes using SHA256 hashing!

SHA256("password") ≠ BCrypt("password")
		↓                      ↓
5e884898da28047...  $2a$12$DQ4skCsan4rSeCh9IY...

They will NEVER match!

SOLUTION APPLIED:
-----------------
✅ Added BCrypt.Net-Next NuGet package
✅ Changed AuthenticateStudentAsync() to use BCrypt.Verify()
✅ Removed old SHA256 HashPassword() method
✅ Project rebuilt successfully

FILES CHANGED:
--------------
1. SchoolPC.Client.csproj
   - Added: BCrypt.Net-Next v4.0.3

2. SchoolPC.Client/DatabaseService.cs
   - Fixed: AuthenticateStudentAsync() method
   - Removed: HashPassword() method
